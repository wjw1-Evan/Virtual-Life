# Virtual Life (虚拟人生)

我们要开发一款基于 Web 的 3D 虚拟人生模拟游戏。玩家将扮演一个虚拟角色，体验符合真实生活作息的模拟生活。

## 📅 项目规划 (Project Plan)

### 1. 核心目标 (Core Objectives)
- **真实生活模拟**：不仅是移动，还需要通过吃饭、睡觉、工作来维持角色的生存状态。
- **3D 沉浸体验**：使用 Three.js 构建 3D 场景，包含日夜交替系统。
- **交互系统**：玩家可以与场景中的建筑物（家、公司、商店）进行交互。

### 2. 功能模块 (Features)

#### 核心系统 (Core Systems)
- **时间系统**：模拟 24 小时日夜循环，影响光照和环境。
- **状态管理**：
    - 🍗 **饥饿度 (Hunger)**：随时间降低，工作时消耗更快。
    - ⚡ **精力值 (Energy)**：随时间降低，工作时消耗更快。
    - 💰 **金钱 (Money)**：通过工作获取，用于购买食物。

#### 场景与环境 (Environment)
- **建筑物**：
    - 🏠 **家 (Home)**：用于睡觉，恢复精力，推进时间到次日早晨。
    - 🏢 **办公室 (Office)**：用于工作，消耗精力/饥饿度，赚取金钱。
    - 🏪 **商店 (Shop)**：用于购买食物，消耗金钱，恢复饥饿度。
- **装饰**：树木、地面纹理、动态光照。

#### 操作控制 (Controls)
- **移动**：W, A, S, D
- **交互**：E 键 (接近建筑物时)
- **视角**：第三人称跟随视角

### 3. 技术架构 (Technical Architecture)
本项目采用原生 JavaScript (ES Modules) + Three.js 开发，无需复杂的构建工具。

- `index.html`: 游戏入口与 UI 界面。
- `style.css`: 界面样式与 UI 反馈。
- `js/Game.js`: 游戏主循环、场景管理、时间系统。
- `js/Character.js`: 角色控制、状态数值管理、交互逻辑。
- `js/World.js`: 地图生成、建筑物与环境渲染。

## 🚀 如何运行 (How to Run)

**重要提示：由于浏览器安全策略 (CORS)，直接双击打开 `index.html` 会导致 module 无法加载。请使用以下方法启动：**


### 方法 1: 使用 Python (如果你已安装 Python)
在项目根目录下打开终端，运行：
```bash
python3 -m http.server
```
然后访问 `http://localhost:8000`

### 方法 2: 使用 Node.js (如果你已安装 Node.js)
在项目根目录下打开终端，运行：
```bash
npx serve .
```
然后访问 `http://localhost:3000`
